Unusuale

A daily guessing game built from Wikipedia's Unusual Articles Page.

Unusuale is a short daily game in several rounds. Each round draws on an entry from Wikipedia's list of unusual articles, and asks you to place it, identify it, or recall a number from it. A new puzzle appears every day, and everyone gets the same one.

Play today's puzzle

Round Types

Each puzzle is a short list of rounds, and each round has a type that determines how you answer it.

  • Multiple choice — pick one of four options.
  • Number — type a figure. Guesses close to the true value earn partial credit.

More types are planned: ordering a handful of entries, naming an article from a description, and placing one on a map.
